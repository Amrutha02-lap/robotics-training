				Linux Preparation - Day 8

Commands Practiced

df -h
Displays disk space usage in a human-readable format.

Syntax:
df -h


free -h
Displays information about system memory (RAM) usage.

Syntax:
free -h


ps
Displays information about currently running processes.

Syntax:
ps


ps aux
Displays detailed information about all running processes.

Syntax:
ps aux
