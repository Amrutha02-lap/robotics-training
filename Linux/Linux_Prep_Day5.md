Commands Learned

nano
Opens a file in the Nano text editor.

Syntax:
nano filename.py

Ctrl + O
Save the file.

Enter
Confirm the filename.

Ctrl + X
Exit Nano.

chmod
Changes file permissions.

Syntax:
chmod +x filename.py

Purpose:
Makes a Python file executable.

python3
Runs a Python program.

Syntax:
python3 filename.py

cat
Displays the contents of a file.

Syntax:
cat filename.txt
