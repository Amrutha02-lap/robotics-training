## Commands Practiced

### echo
Displays text or values in the terminal.

Syntax:
echo text

Example:
echo "ROS2 Training"


### id
Displays user ID, group ID, and group information.

Example:
id


### df -h
Displays disk space usage in a human-readable format.

Example:
df -h


### free -h
Displays system memory usage in a human-readable format.

Example:
free -h
