## Commands Practiced

### mkdir -p
Creates directories, including parent directories if required.

Syntax:
mkdir -p directory/path

Example:
mkdir -p practice/day12


### find
Searches for files and directories.

Syntax:
find path -name "filename"

Example:
find ~/robotics-training -name "while_loop.py"


### du -sh
Displays the total size of a directory in a human-readable format.

Syntax:
du -sh directory

Example:
du -sh ~/robotics-training


### ls -lh
Displays files with details such as permissions and file size in a human-readable format.

Example:
ls -lh
