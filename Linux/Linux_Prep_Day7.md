Commands Learned

colcon build
Builds all ROS2 packages in the workspace.

Syntax:
colcon build

source
Loads the ROS2 workspace environment.

Syntax:
source install/setup.bash

ros2 pkg list
Displays all installed ROS2 packages.

Syntax:
ros2 pkg list

ros2 run
Runs a ROS2 executable.

Syntax:
ros2 run package_name executable_name

ros2 service list
Lists all active ROS2 services.

Syntax:
ros2 service list

find
Searches for files and directories.

Syntax:
find ~ -name "filename"

cp
Copies files.

Syntax:
cp source destination

mv
Moves or renames files.

Syntax:
mv source destination
