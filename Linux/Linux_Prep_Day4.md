Ubuntu & ROS2 Setup

sudo
Runs a command with administrator (superuser) privileges.

Syntax:
sudo command_name

Example:
sudo apt update

apt update
Updates the package list from Ubuntu repositories.

Syntax:
sudo apt update

apt upgrade
Upgrades all installed packages to their latest versions.

Syntax:
sudo apt upgrade

apt install
Installs a software package.

Syntax:
sudo apt install package_name

Example:
sudo apt install python3-pip

echo
Prints text or appends text to a file.

Syntax:
echo "Hello"

source
Executes a shell script in the current terminal.

Syntax:
source /opt/ros/humble/setup.bash

Purpose:
Loads the ROS2 environment variables into the current terminal.

printenv
Displays environment variables.

Syntax:
printenv

which
Shows the location of an executable command.

Syntax:
which python3
which ros2
