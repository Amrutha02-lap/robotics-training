## Commands Practiced

### cp -r
Copies a directory recursively.

Example:
cp -r source_folder destination_folder

### rm -r
Removes a directory and its contents.

Example:
rm -r folder_name

### mkdir -p
Creates nested directories if required.

Example:
mkdir -p practice/day14

### ls -la
Shows all files including hidden files with details.

Example:
ls -la
