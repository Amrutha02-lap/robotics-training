                                                   Linux Fundamentals — Day 1

 What is Linux?

Linux is an open-source operating system kernel. The kernel is the core part of an operating system and communicates with hardware such as the CPU, memory and storage.

 What is Ubuntu?

Ubuntu is a Linux-based operating system distribution. It is widely used in software development, artificial intelligence, cloud computing, servers and robotics.

 Why is Ubuntu used in robotics?

ROS2 is mainly developed and tested on Ubuntu. Ubuntu is stable, secure and provides good support for robotics software, development tools and hardware.

 Why do robotics engineers use Linux?

Robotics engineers use Linux because it provides good performance, powerful programming tools, hardware access and strong support for ROS2.

 Terminal

A terminal is a program that allows users to interact with the operating system by typing commands.

 Shell

A shell reads commands entered in the terminal and communicates with the operating system to execute them.

 GUI and CLI

GUI means Graphical User Interface. It uses windows, icons, menus and a mouse.

CLI means Command-Line Interface. It allows users to interact with a computer using text commands.

 Bash

Bash means Bourne Again Shell. It is a commonly used shell that interprets and executes commands.

 Commands Practised

- pwd — displays the current working directory.
- ls— lists files and directories.
- cd — changes the current directory.
- mkdir — creates a new directory.
- rmdir — removes an empty directory.
- touch — creates an empty file.
- cat — displays file contents.
- cp — copies a file or directory.
- mv — moves or renames a file.
- rm — removes a file.
- history — displays previously executed commands.
- clear — clears the terminal screen.
- echo — displays or writes text.
- > — writes text by replacing existing content.
- >> — appends text to existing content.
