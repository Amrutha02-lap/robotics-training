				Linux Preparation - Day 3

Commands Learned

date
Shows the current system date and time.

uname -a
Displays detailed system information.

hostname
Displays the computer name.

tar
Creates an archive file.

Syntax:
tar -cvf file_name.tar folder_name

View files inside the archive:
tar -tvf file_name.tar

head
Displays the first few lines of a file.

Syntax:
head file_name.md

tail
Displays the last few lines of a file.

Syntax:
tail file_name.md
