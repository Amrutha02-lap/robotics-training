            		    Git Preparation - Day 6

Commands Learned

git status
Shows the current repository status.

Syntax:
git status

git add
Stages files for commit.

Syntax:
git add .

git commit
Creates a commit with a message.

Syntax:
git commit -m "message"

git push
Uploads local commits to GitHub.

Syntax:
git push origin main

git pull --rebase
Downloads remote changes and reapplies local commits.

Syntax:
git pull origin main --rebase

.gitignore
Used to ignore unnecessary files such as:

build/
install/
log/
__pycache__/
